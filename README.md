# Autocall Structuring

A one-page site by Jules Ventre on a Euro Stoxx 50 autocallable note with a memory coupon: priced under local volatility calibrated to Eurex option settlements, cross-checked by a PDE, then stressed and hedged. Every computed figure on the page is read from the project's results files.

https://julesvntr.github.io/autocall/

Data as of 23 October 2026.
